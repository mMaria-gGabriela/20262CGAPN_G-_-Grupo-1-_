# 20262CGAPN_G -Grupo-1- Portfólio da disciplina Análise de Dados para Pesquisas em Políticas Públicas (CGAPN) — 2º Semestre 2026, Professora Érica Siqueira.


Este repositório reúne projetos desenvolvidos por Camile Vitória Pereira, Danielle Mickaelly Lourenço da Silva, Henrique Silva, Manuela Fasti, Maria Gabriela Espírito Santo, como parte da disciplina de Análise de Dados para Pesquisas em Políticas Públicas.

O principal objetivo deste repositório é documentar e compartilhar os conhecimentos e aprendizados adquiridos ao longo da disciplina, apresentando, de forma prática, como ferramentas de análise de dados podem ser aplicadas à interpretação de informações e ao apoio à tomada de decisões no contexto de políticas públicas. Os projetos apresentados foram desenvolvidos a partir de situações e bases de dados, explorando diferentes técnicas de tratamento, organização, análise e visualização de dados. Além de registrar os resultados obtidos, o repositório busca demonstrar a evolução do aprendizado ao longo do curso e servir como um espaço de consulta e compartilhamento.

## Projeto 1 — Simulador de Repasse do PNAE

O Projeto 1 consiste em um simulador em Excel para calcular o repasse financeiro anual do Programa Nacional de Alimentação Escolar (PNAE) para a EMEB Vila Quitaúna, com base nos valores per capita e nas regras de cálculo estabelecidas pela Resolução CD/FNDE nº 1/2026. Para a construção do simulador, foram utilizadas funções como PROCV, SE aninhado com E/OU e SOMARPRODUTO, além de uma Tabela de Dados para testar diferentes cenários de acordo com a variação no número de matrículas.

O projeto também conta com um artefato HTML interativo, desenvolvido com apoio de Inteligência Artificial, que reproduz o cálculo do simulador em uma interface navegável.

## Projeto 2 — Dashboard Censo Escolar

O Projeto 2 consiste na construção de um dashboard a partir dos microdados do Censo Escolar da Educação Básica 2024 (INEP), com foco nas escolas do município de São Paulo.

A base de dados foi tratada e organizada por meio de colunas calculadas, tabelas dinâmicas, gráficos dinâmicos e segmentações, permitindo a análise de diferentes indicadores educacionais.

O dashboard apresenta informações sobre infraestrutura escolar, incluindo água, energia, esgoto e lixo, além da distribuição das escolas por zona da cidade, rede de CEIs e perfil das matrículas por cor/raça, sexo e faixa etária.
